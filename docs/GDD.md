# 《推币机的狂欢》（COIN CARNIVAL）完整游戏策划案（GDD）

> **设计目标**：融合《欢乐推币机2》的街机摆动投币、钉阵折射、往复斜口中奖门与梯形推台物理拉扯，以及《弹珠爆破》的满屏数字膨胀、双轴乘法爆分、家族协同与高节奏肉鸽构筑，打造一款**手机竖屏单手可玩、零 3D 发烫压力、全链路闭环成品级**独立肉鸽推币游戏。

---

## 1. 核心愿景与技术决策

### 1.1 视觉与性能定位
- **美术风格**：**2.5D 俯斜视角 · 高饱和街机霓虹风**（Neon Arcade）。
  - 深午夜紫蓝底（`#0B0D1E`）配霓虹青（`#33E6FF`）、电光洋红（`#FF3D8E`）、聚能紫（`#A66CFF`）、狂欢暖金（`#FFD23F`）。
  - 通过纯 **NanoVG 2D 渲染**实现假 3D 金属硬币厚度侧边、高光扫光、背板玻璃反射、机械推板立体活塞与跑马灯追逐特效。
- **移动端性能底线**：
  - 彻底放弃 3D 物理引擎，使用自研轻量化 **2D 推币与钉阵物理引擎**；
  - `Physics`、`Fx` 全量采用**预分配扁平数组对象池**与 `12×16` 空间哈希网格；每帧 `Update/Render` **零 Lua 临时表创建**；
  - 上限同屏 `110` 枚动态硬币 + `320` 粒子 + `96` 分级暴击飘字，稳跑 60 FPS 不发烫。
- **贴图热替换架构**：
  - 所有 UI 面板走 `Skin.TEXTURES`（九宫格切片），机台/硬币/遗物/Boss/事件插画走 `Skin.SPRITES`；当前全部程序化绘制立即可玩，后期放入 PNG 至 `assets/image/` 即自动热生效。

## 2. 舞台坐标系与物理推币机制

### 2.1 世界坐标系（`WORLD_W = 360, WORLD_H = 600`）
竖屏舞台等比自适应居中置于顶部状态栏与底部操作区之间：

```
y = 0..240   [上部落币钉阵区]
  y = 32       顶部摆动发射炮口 (x = 180, 摆角 ±42°, 周期 2.45s 锁相)
  y = 68..188  错位霓虹挡钉阵 (6 行错位排列，含功能特殊钉)
  y = 216      底部左右往复斜口中奖门 (净口宽 28px ≈ 1.47×币径; 两侧带 ±14° 弹性斜沿门板)
y = 240..570 [下部 2.5D 梯形推台区]
  y = 242..332 机械往复推板 (周期 3.4s 正弦往复, 行程 56px, 推板前缘把硬币往前推挤)
  y = 246..540 梯形主台面 (顶宽 228px → 底宽 304px; 下段两侧 y=455..540 为开放侧漏缝!)
  y = 540      前沿悬崖收集线 (带轻微阻挡唇阻尼，硬币堆满压线后倾泻跌落!)
  y > 544      前端收集爆分区 (触发得分爆发 + 特殊币特技 + 飞币)
  x 越出斜边   侧漏损耗区 (若无护栏遗物/磁铁拉回则直接落空损耗)
```

### 2.2 物理核心规则
1. **摆动投币与钉阵弹跳**：
   - 玩家点按舞台任意位置或底栏「投币 / 自动」按钮，消耗 1 枚当前队列弹药币从炮口以初速 `270 px/s` 沿摆动角度射入落币槽。
   - 币穿过钉阵产生弹性折射；若撞击到**特殊功能钉**（`×2` 倍增钉、分裂钉、雷电钉、炸弹钉、聚能钉），立即触发对应得分/特效/连击。
   - 槽内触发 **3.5 秒防卡死保险丝**：滞留或低速卡死时自动施加横向微推或安全兜底出槽，杜绝死锁。
2. **往复斜口中奖门（同频锁相）**：
   - 中奖门与发射口同周期摆动（相位同步，熟练玩家可踩点预判投中！）。
   - **正面穿过中奖口**：触发中奖闪光 + 狂欢槽 `+16%` + 触发**迷你幸运轮盘**（加币 `+1~2` / 倍率 `+0.5` / 召唤暴金雨 / 立刻向推台空投 2 枚额外币），并把该币直接送到推板前方继续推挤！
   - **擦边撞到斜沿门板**：高弹性弹向两侧落入推台后方，不触发中奖奖励。
3. **推台挤压与侧漏拉扯**：
   - 每关开局预设 **36 枚基础铺台币**整齐码放在推板前与梯形前沿悬崖边缘，让第 1 秒就能看到推掉硬币的快感。
   - 推板前伸时对后方硬币施加连续前向推力；硬币间进行 **3 迭代圆-圆分离与动量传递**，层层挤压形成多米诺骨牌式前推。
   - **前沿微阻挡唇**提供恰到好处的静摩擦阻塞，使得硬币会在悬崖边积蓄张力，一旦越过即成片倾泻！
   - **侧漏风险与博弈**：梯形下段斜边在 `y = 455..540` 留有侧漏缝；强力爆炸或混乱碰撞可能把边缘币挤进侧漏，玩家可通过「合金护栏」遗物或「磁石币」把侧漏转化为收益。
   - **同屏上限超频转化**：当台面币超过 `110` 枚时，最老的边缘普通币自动“超频熔解”折算为双倍即时筹码直接飞入计分板，保证 100% 流畅不卡顿。

## 3. 满屏数字双轴膨胀体系

### 3.1 核心公式（蓝 Chips × 红 Mult × 黄金暴击连击）
$$\text{单次爆分} = \lfloor \text{BaseChips} \times \text{TotalMult} \times \text{CritMult} \times \text{ComboMult} \rfloor$$

- **蓝轴 · 基础筹码（Chips）**：硬币基础分 + 钉阵累加 + 特殊币/遗物固定筹码。
- **红轴 · 狂欢倍率（Mult）**：初始 `1.0×`，每次连击、特殊钉命中、过中奖门、倍率系硬币跌落、Fever 状态都会叠加/乘算倍率。
- **连击阶梯（Combo）**：`4 秒` 连续得分窗口不中断，每 5 连击额外 `+10%` 乘区，突破 `15/30/60` 连击依次点亮蓝/金/霓虹紫屏边光晕与升调音效。
- **暴击（Crit）**：基础 `10%` 暴击率，`2.0×` 暴击倍率，由遗物/狂欢币/协同档位大幅放大，暴击弹出更大尺寸金色/红紫描边巨字并伴随微顿帧与震屏！
- **狂欢时刻（FEVER CARNIVAL）**：
  - 狂欢能量槽满 `100%` 立刻爆发 **8 秒狂欢**：
  - 自动倾泻 **16 枚高能金币雨**直落推台、推板速度 `×1.75`、全局倍率 `×2.0`、暴击率 `+25%`、彩虹流光灯带环绕机台、BGM 鼓点声道推至全满！

### 3.2 大数字缩写规范
统一由 `Number.lua` 导出：
- `< 10,000`：整数显示（如 `1,280` 或 `1280`）
- `≥ 10,000`：`%.1f万`（如 `3.6万`）
- `≥ 100,000,000`：`%.2f亿`（如 `1.45亿`）
- `≥ 1,000,000,000,000`：`%.2f兆`（如 `2.80兆`）

## 4. 战役结构、经济与肉鸽构筑

### 4.1 三幕战役（18 关 + 无尽 + 20 难度 + 每日挑战）
每幕固定 **6 层结构**：
- 第 1 层：普通关（开局熟悉节奏，**前 3 关通关率 ≥ 95%**）
- 第 2 层：分岔选择（普通关 / 精英双倍赏金关）
- 第 3 层：补给分岔（商店 / 奇遇事件）
- 第 4 层：普通关 / 精英关
- 第 5 层：整备分岔（整备工坊 / 秘宝宝箱）
- 第 6 层：**幕末 Boss 战**

| 幕数 | 主题 | 目标分跨度 | Boss 名称 | Boss 机制 |
|---|---|---|---|---|
| 第 1 幕 | 霓虹游艺厅 | `900` → `1.6万` | **铁闸庄家** | 每 6s 开关中奖门 2.5s，同时每隔 7s 抬起前挡唇蓄币 |
| 第 2 幕 | 黄金熔炉 | `3.5万` → `160万` | **熔金巨轮** | 周期空投占道「熔渣币」（推落或炸毁爆出 8× 熔金大奖） |
| 第 3 幕 | 赛博金库 | `400万` → `1.2亿` | **终极吞金兽** | 场内锁死 1 个装甲护盾直到累积击碎，推落「金库币」爆 40× 超分 |
| 无尽模式 | 超频狂欢 | 指数膨胀至 `兆` | **周期叠加双词缀** | 第 3 幕通关后一键进入无尽冲榜 |

### 4.2 心数、弹药与商店经济
- **生命值**：开局 `5 ♥`（上限 `8 ♥`）。未达过关目标分时按剩余护盾比例扣 `1~2 ♥` 并依然推进（不会卡关憋死），`0 ♥` 结算失败。
- **弹药队列**：开局 `10` 枚基础铜/银币 + 每关补强；每关可投 **20 枚**（循环从队列抽取，打空后循环洗牌直到本关投币数用尽且台面静止或过关）。
- **商店货币（黄金券 Tickets）**：
  - 过关固定奖（`18~30`）+ 剩余投币折算（每枚 `+2`）+ 超额分奖（最高 `+12`）+ **复利利息**（每存 `25` 券给 `+5`，封顶 `+15`）。
  - 商店支持：购买特殊币、购买遗物、删去废币（起价 15 券递增）、刷新货架。
